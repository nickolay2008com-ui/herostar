# HeroStar ✦

HeroStar — сервис, который помогает человеку посмотреть на реальную жизненную ситуацию через механику его натальной карты.

Главный продукт — **Звёздный клон**. Пользователь создаёт персональную модель по данным рождения, описывает ситуацию и получает альтернативный ход с объяснением факторов, которые повлияли на ответ.

**Сайт:** https://herostar.up.railway.app

## Что делает сервис

- создаёт персональную карту по данным рождения;
- показывает ключевые особенности человека понятным языком;
- помогает разбирать выборы, сомнения и сложные ситуации;
- объясняет, какие части карты относятся к конкретному ответу;
- поддерживает продолжительный диалог;
- сохраняет карту и историю пользователя;
- поддерживает авторизацию, оплату и административную аналитику.

## Принцип продукта

HeroStar не предсказывает будущее и не принимает решения за человека.

Сервис создаёт дополнительную позицию для размышления:

**ситуация → значимые факторы карты → внутреннее противоречие → возможный ход → практическое действие.**

Основная ценность — не общий гороскоп, а применимый разбор конкретной ситуации.

## Основные разделы

- создание персональной карты;
- диалог со Звёздным клоном;
- объяснение факторов текущего ответа;
- паспорт и визуальное представление карты;
- сохранение доступа через Telegram;
- платные расширенные режимы;
- административная панель и воронка продукта.

## Архитектура

Проект состоит из нескольких основных частей:

```text
public/      пользовательский интерфейс
src/         расчёты, бизнес-логика, доступы и интеграции
server.js    сервер и API
```

Расчёт карты, интерпретация, диалог, хранение данных и аналитика разделены между независимыми модулями. Это позволяет развивать продукт без полной переделки системы.

## Локальный запуск

```bash
cp .env.example .env
npm install
npm start
```

После запуска приложение доступно по адресу:

```text
http://localhost:3000
```

Для полноценной работы необходимо настроить переменные окружения и подключить используемые внешние сервисы.

## Развёртывание

Проект рассчитан на стандартное серверное развёртывание с:

- Node.js;
- базой данных;
- защищёнными переменными окружения;
- автоматическим деплоем из основной ветки;
- проверкой состояния приложения.

Основная ветка для production — `main`.

## Данные и безопасность

- чувствительные ключи не хранятся в репозитории;
- доступ администратора защищён;
- действия оплаты проверяются на сервере;
- аналитика отделена от личного содержания диалогов;
- публичные события сохраняются без сырого IP-адреса;
- пользовательские данные обрабатываются только после согласия.

## Продуктовые принципы

- сначала ценность, потом регистрация;
- конкретная ситуация важнее общего описания личности;
- ответ должен объясняться через реальные факторы карты;
- интерфейс должен снижать сложность, а не демонстрировать её;
- аналитика должна показывать путь пользователя до полезного результата;
- изменения продукта принимаются на основе поведения пользователей и измеримых данных.

## Статус

Проект находится в активной разработке и тестировании рекламной воронки.
